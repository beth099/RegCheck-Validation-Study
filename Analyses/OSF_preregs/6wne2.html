Effects of response set (bimanual vs. unimanual) on a compatibility effect between stimulus size and response position.

OSF ID: 6wne2 | Registered: 2021-05-04T13:30:15.189928

Study Information

Hypotheses

1a. If the compatibility effect is restricted to bimanual response sets, the effect should only occur for the bimanual response set, but not for the unimanual sets. In statistical terms, this pattern should produce a significant interaction of S-R mapping and response set. 1b. If the compatibility effect is independent of response set, the effect should occur in all three sets with a similar effect size. In statistical terms, this pattern should produce a significant main effect of S-R mapping, but no interaction between mapping and response set. 1c. If the compatibility effect is stronger for the bimanual response set than for the unimanual response sets, it should occur for all three sets, but with a stronger effect size for the bimanual set. In statistical terms, this pattern should produce a significant main effect of S-R mapping, and a significant interaction of S-R mapping and response set. 2. With unimanual response sets, the possibility exists that one response is more salient than the other. In particular, with left-hand responses, the left response (e.g., with the middle finger) may be more salient than the right response (e.g., with the index finger). Similarly, with right-hand responses, the right response (e.g., with the middle finger) may be more salient than the left response (e.g., with the index finger). To test for differences between unimanual response sets only, we will use a three-factorial design (2 Stimulus × 2 Response × 2 Response set). If the compatibility effect is stronger for the more salient response within each unimanual response set, a significant three-way interaction should emerge in this analysis.

Study design

We are planning two sets of analysis on our data. (1) The first analysis will test between hypotheses 1a, 1b, and 1c (described above) with a two-factorial design. This design involves S-R mapping (compatible vs. incompatible) and Response Set (unimanual left, unimanual right, bimanual) as within-subjects factors. Reaction Times (RTs) of correct responses and error percentages will serve as dependent variables. (2) The second analysis will test hypothesis 2 (described above) with a three-factorial design. This design involves Stimulus (small, large), Response (left finger, right finger) and Response Set (unimanual left, unimanual right) as within-subjects factors. We will counterbalance the order of stimulus sets and S-R mappings across participants.

Randomization

We will randomize trials within blocks.

Data collection procedures

Participants will be recruited through advertisements on internet platforms for students of TU Dortmund University (in Moodle, or Facebook). Participants will be compensated either by course credits, or by payment of 10 Euro. Participants must be aged between 18 and 40 years, and right-handed. We will test handedness by a modified version of the Edinburgh Handedness Inventory (EHI).

Sample size

Our target sample size is 72 participants.

Sample size rationale

We know from previous studies on spatial S-R compatibility effects that spatial compatibility effects occur for bimanual and unimanual response sets with (often) similar effect size. In a previous study (Wühr &amp; Seegelke, 2018), we have observed a strong compatibility effect of partial eta² = .33. Given this value, we decided to collect data from 72 participants, because this sample size allows us to detect a 2 x 3 interaction of moderate size (i.e., partial eta² = .10) with high power (1-beta = .95) at the standard .05 alpha error probability. We used the software MorePower for conducting our power analysis.

Stopping rule

We will have control over the sample size.

Variables

Manipulated variables

We will manipulate the independent variables “Stimulus”, “Response” and “Response Set”. The variable “Stimulus” will have the levels “small” (e.g., 1 cm) and “large” (e.g., 3 cm). The variable “Response” will have the levels “left” and “right”. The variable “Response Set” will have the levels “unimanual left” (i.e., middle and index finger of left hand), “unimanual right” (i.e., index and middle finger of right hand), and “bimanual” (i.e., index fingers of left and right hand). All variables will be manipulated within participants. For testing some hypotheses, the variables “Stimulus” and “Response” will be combined to the variable “S-R Mapping” with two levels “compatible” (small S – left R; large S – right R) and “incompatible” (small S – right R; large S – left R).

Measured variables

The primary dependent variable will be Reaction Time (RT) of correct responses. A secondary dependent variable will be the percentage of errors. Moreover, we will compute a Handedness Score from participants’ responses to the EHI.

Indices

If appropriate, we may compute an index of the compatibility effect by subtracting mean RT (or error percentage) in conditions with a compatible S-R mapping from mean RT (or error percentage) in conditions with an incompatible S-R mapping.

Analysis Plan

Statistical models

For our first analysis, we will use a two-way ANOVA, with “S-R mapping” (compatible vs. incompatible) and “Response Set” (unimanual left, unimanual right, bimanual) as within-subjects factors. The dependent variables will be RT (of correct responses), and error percentages. For our second analysis, we will use a three-way ANOVA, with “Stimulus” (small, large), “Response” (left, right), and “Response Set” (unimanual left, unimanual right) as within-subjects factors. If the interactions were significant, we may use planned comparisons (i.e., t tests if the distribution of the dependent variable is normal; Wilcoxon tests if the distribution is not normal) for determining the form / source of interaction.

Transformations

We are not planning to perform transformations.

Inference criteria

We will use the standard p&lt;.05 criteria for determining if the ANOVA and the post hoc test suggest that the results are significantly different from those expected if the null hypothesis were correct.

Data exclusion

We will check for outliers on two levels. Firstly, in each data set, we will exclude RTs that are shorter than 100 ms, or longer than 1,500 ms. Both of these cases are typically rare in experiments of this type. We will then report the (average) percentage of these two cases. Secondly, we will check for outliers in parameters of overall performance (i.e., overall RT, overall error percentage). An outlier is an observation that deviates more than 2.5 standard deviations from the grand mean of this measure. Outliers (i.e., data sets including outliers) will be eliminated from data analyses.

Missing data

If a data set is incomplete (e.g., due to technical malfunction, or because a participant quits the experiment before all trials are completed), this subject (data set) will not be included in the analysis.

Exploratory analysis

At present, we are not planning any exploratory analysis.
