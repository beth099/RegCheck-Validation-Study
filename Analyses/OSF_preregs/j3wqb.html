Critical Test of the Unequal Variance SDT Recognition Model

OSF ID: j3wqb | Registered: 2022-01-20T15:20:55.995331

Study Information

Hypotheses

1. When d is held constant the variance parameter of the UEVSDT model predicts decreasing performance on a novelty detection three alternative forced choice (3AFC) task. 2. When d is held constant the recollection parameter of the dual process signal detection (DPSDT) model predicts increasing performance on a novelty detection 3AFC task.

Study design

The design is a fully within subjects comparison of the predictions of the UEVSDT and DPSDT models. It will consist of two study/test cycles. In cycle I subjects will study singly presented words (duration approximately 2 seconds) and be subsequently tested on single item recognition (old or new) accompanied by confidence judgments (low, medium, high) (self-paced responding). The study list will contain 60 words with 120 in the test list. The data will be fit via Matlab using an ROC fitting package provided by Yonelinas and colleagues to obtain d and variance parameters for the UEVSDT model and d and r parameters for the DPSDT model. In cycle II the subjects will complete the novelty 3AFC task. Each subject will study 60 words (in the same fashion as cycle I and then will complete 30 test trials of novelty 3AFC in which each trial contains a new word not shown in the experiment and two of the prior study words (randomly sampled from the study list). Their task is to select the new item and responding is self-paced. This procedure will be repeated, yielding at total of two old/new recognition cycles and two Novelty 3AFC cycles for an ON-N_3AFC-ON-N_3AFC interleaved sequence. It is the relationship between the fitted parameters from old/new recognition tests and the accuracy of performance in the Novelty 3AFC tests (percent correct) that is the focus of the hypotheses.

Randomization

Stimuli are randomly assigned to trial position and study/lure status from a pool of words

Explanation of existing data

Data collection procedures

Subjects will be recruited from Prolific, Amazon Mechanical Turk, or the Departmental Subject Pool. Prolific is the anticipated source. The pay per subject will be determined at the initiation of the experiment.

Sample size

Target sample size is 84, which would yield 80% power for a medium effect size population r of .30. Data collection will be stopped after the first several subjects to allow an analysis check of the coding of the data, ensuring the programming is accurately reporting subject performance. Since Ns of several subjects are not reportable, and the predetermined stopping N is 84 or greater, this imposes no threat of alpha inflation.

Variables

Manipulated variables

This is technically an observational study in which two decision models make categorically divergent empirical relationships between the parameters of fitted single item recognition decision models and the performance of a Novelty 3AFC task..

Measured variables

Response accuracy and confidence during recognition testing.

Indices

Single item recognition confidence data will be fit via ML procedures to yield decision model parameters (two per subject) which will then be used in linear multiple regression.

Analysis Plan

Statistical models

Multiple regression. The two key parameters of each model will be entered as predictors of Novelty 3AFC percentage correct. If a positive association is found between the DPSDT r parameter and performance is found it will confirm the model. If a negative association is found between the UEVSDT sigma parameter and performance it will confirm the model.

Transformations

Inference criteria

Frequentist p-values for regression coefficients.

Data exclusion

Subjects yielding parameters that are impossible (e.g., rs greater than 1) or greater than 3 standard deviations away from the sample values will be replaced.

Missing data

Only subjects completing the experiment will be including. Responding is required on every trial.

Exploratory analysis

The primary exploratory question will be whether there is a way to characterize the asymmetry of the ROC, somehow normalized for area, that can be used for predicting novelty 3AFC performance. If so, this would eliminate the need for fitting the parametric decision models in order to test the relationship between ROC asymmetry and novelty 3AFC performance. Simulations will be conducted to show that this method behaves as expected when either UEVSDT or DPSDT models generate synthetic ROC data.
