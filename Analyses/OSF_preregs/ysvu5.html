Individual differences in attention capture oculometrics

OSF ID: ysvu5 | Registered: 2023-09-13T16:11:44.996786

Study Information

Hypotheses

Hypothesis 1: Attention capture costs, measured via reaction time, will negatively correlate with working memory capacity and attention control. Hypothesis 2: Attention capture costs, measured via reaction time, will positively correlate with oculometric indicators of attention capture. Hypothesis 3: Oculometric indicators of attention capture will negatively correlate with working memory capacity and attention control. Hypothesis 4: Pupillary measures of attentional intensity will positively correlate with working memory capacity and attention control, and negatively correlate with RT measures of attention capture. Hypothesis 5: Pupillary measures of attentional consistency will positively correlate with working memory capacity and attention control, and negatively correlate with RT measures of attention capture.

Explanation of existing data

We have pilot data from several research assistants that has been examined to verify the data files include all important variables.

Data collection procedures

Participants are recruited from the human subjects pool at the University of Texas at Arlington. All participants are thus university students. The minimum age is 17, and there is no maximum age to complete the study. However, we will exclude participants older than 40 from the analyses to avoid age-related confounds. Participants are awarded partial course credit for their participation.

Sample size

Our minimum target sample size is 340.

Sample size rationale

Our target sample size is based on simulations published by Schonbrodt &amp; Perugini (2013), which demonstrate that this sample size is sufficient to precisely estimate a population correlation of +/- 0.20 within a corridor of stability of 0.10 with 90% confidence. At this sample size, we would also have 95% power to detect a correlation of +/- 0.20 with 95% power (alpha = 0.05).

Stopping rule

If we exceed this target sample size in a single academic semester, we will use the end of the semester as the stopping rule for data collection. If we do not meet our minimum target sample within a single semester, we will resume data collection at the beginning of the next semester until we reach the target sample size of 340.

Variables

Manipulated variables

Within the working memory tasks, the only within-subjects variables are set size. Within the attention control tasks, the within-subject variables are cue-target delay. Within the attention capture task, the within-subject variable is distractor presence.

Measured variables

Operation span - total number of items recalled in correct serial position Symmetry span - total number of items recalled in correct serial position Color change-detection - "K" (set size * [hit rate - false alarm rate]) Orientation change-detection - "K" (set size * [hit rate - false alarm rate]) Antisaccade - proportion of correct target identifications SACT - proportion of correct target identifications PVT - average of slowest quintile of RTs Attention capture (behavior) - average RT on distractor-present trials, average RT on distractor-absent trials, distractor-present/absent difference Attention capture (eye-tracking): - Time-to-target: Elapsed time to target fixation - Saccades-to-target: Number of saccades to target fixation - Path ratio for spatial search efficiency: sum of amplitudes of all saccades before first entry in target region divided by distance between the fixation position at search onset and target location, 1 = maximally efficient; &gt;1 increasingly less efficient - Initiation time: time to initiate first saccade - Scanning time: time between first saccade to first fixation in target region - Verification time: time between first fixation in target region and manual response - Capture probability: probability that a color singleton is fixated (first saccade) - Refixation: number of times gaze is directed to particular region, leaves, then comes back - Pretrial pupil diameter: mean pupil diameter during last 1,000 ms of pretrial fixation screen, (within-participant mean, standard deviation, and coefficient of variation) - Task-evoked pupillary response: trial-by-trial standardized change in pupil diameter from period immediately preceding stimulus onset For all variables, we will use a multipass +/- 3 standard deviation outlier screening method. We will pass the outlier threshold over each variable until no cases need to be excluded, and we will record the number of passes for each variable. For the psychomotor vigilance and visual search tasks, we will first perform the multipass +/- 3 SD threshold on the RT data before computing within-participant means. Participants will also need to have at least 75% accuracy on the visual search task to be included in the analysis. For the eye-tracking data, we will exclude values which the eye-tracker tags as invalid. If a trial has fewer than 50% of its samples as valid, it will be excluded from the analysis. Then, any participant with fewer than 50% of their trials remaining will be excluded from the oculometric and pupillary analyses. For pupillary dilations, pupil diameter will first be screened to include only physiologically plausible values (&gt; 1 mm and &lt; 9 mm).

Indices

Attention control score - z-score average of antisaccade, SACT, and PVT(*-1) Working memory score - z-score average of operation span, symmetry span, color change-detection, and orientation change-detection We will also use factor analysis to examine the number of dimensions in the oculometric data from the attention capture task.

Analysis Plan

Statistical models

The analysis will report: - Zero-order correlations among all observed variables - Descriptive statistics (N, Mean, Standard Deviation, Minimum, Maximum, Skew, Kurtosis) for all observed variables. - Analysis of (correct) RTs in the attention capture task. We will specific a linear mixed model with trial-level RT data submitted to a model with fixed effects for distractor presence, sum-to-zero effects coded (1 = distractor-present, -1 = distractor-absent), and a random effect of participant (both intercept and slope allowed to vary). Then, in separate models, we will enter working memory capacity and attention control scores into the models as covariates, which are allowed to have both a main effect and an interactive effect with distractor presence. This will allow us to examine whether working memory capacity (WMC) and/or attention control (AC) affect overall RTs (significant main effect of score), whether they moderate the effect of target presence (significant score x distractor presence interaction), or both. Hypothesis 1 predicts WMC x distractor presence and AC x distractor presence interactions. Finally, we will enter WMC and AC into the model as covariates simultaneously to examine which factor drives the relations, if any. These analyses will be conducted using the lmerTest package in R. Because there are so many oculometric indices extracted from the attention capture data, we will use a dimension reduction technique. Specifically, we will employ exploratory factor analysis (EFA) with the lavaan package in R. We expect there to be at least one coherent factor derived from the oculometric data, which will indicate visual search efficiency (e.g., longer time to fixate on target, more saccades on non-targets before target fixation) and/or overt visual attention capture by a singleton (proportion of distractor-present trials in which the singleton is fixated) Once these factors are identified, we will use the predict() function in lavaan to extract factor scores, and these will be correlated with the behavior indices of attention capture (Hypothesis 2) and the WMC and AC factor scores (Hypothesis 3). Finally, we will use multiple regression to examine the shared and unique influences of WMC and AC on the oculometrics. For the pupillary data, will compute the average change in pupil diameter to distractor-present and distractor-absent trials over the 1,500-ms window post stimulus onset. Then, these values will be correlated with the WMC and AC scores and the behavioral and oculometric attention capture measures (Hypothesis 4). Specifically, we hypothesize that larger pupillary responses will correlate with higher WMC, better AC, lower attention capture, and better visual search efficiency. We will then compute the intraindividual mean and intraindividual standard deviation of pretrial pupil diameter for each participant, and this value will be correlated with the WMC and AC factor scores, the attention capture RT effect, and the oculometric factors (Hypothesis 5). Specifically, we hypothesize that less intraindividual variability in pretrial pupil diameter will correlate with higher WMC, better AC, lower attention capture, and better visual search efficiency.
